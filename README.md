Create a movie recommendation system based on the MovieLens 10M Dataset.

data: Contains the raw data, extracted from: http://grouplens.org/datasets/movielens/10m/

figs: Contains all the relevant graphs and figures extracted from the analysis.

rda: Contains the wrangled dataset built for the analysis.

analysis: Script containing the modelling approach and insights related to it.

download-data: Script containing the download and importing process of the raw data.

wrangle_data: Script containing the data-frames construction and variables formatting.
